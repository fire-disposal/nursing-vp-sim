# 08 — 现状与演进方向

> 更新: 2026-06-15

## 当前系统能力

### 已交付的核心闭环

```
学生选择 Practice → 与 AI 患者对话 → 自动评分 → 教师复核
```

| 模块 | 状态 | 说明 |
|------|------|------|
| 虚拟患者对话 | 完成 | SSE 流式 + 四阶段（问候→采集→体检→结束）+ 关键词隐藏信息 |
| 自动评分 | 完成 | 19 项 LLM 评分 + 证据化反馈 + 100 分制 |
| 教师复核 | 完成 | ScoreReview 独立表，教师逐项修改 + 备注 + 复核徽章 |
| Practice 管理 | 完成 | 三种模式（training/assessment/free_play），插件按需配置 |
| 训练计时 | 完成 | 20 分钟倒计时，<5 分钟警告，到时自动结束 |
| 采集进度 | 完成 | 客户端关键词匹配，不调 LLM |
| 仪表盘 | 完成 | 学生/教师角色分流 + StatCard + 趋势图 |

### 已交付的扩展功能

| 模块 | 状态 | 说明 |

| 患者主动提问 | 完成 | LLM 驱动的患者主动发起 |

### 功能缺口（当前生产状态）

**P0 阻碍交付（~3 工时）：**
- messages_pkey 主键冲突（生产日志报错）
- 数据库备份接口 404

**P1 交付前应补齐（~10 工时）：**
- 移动端响应式布局
- 断网检测 + SSE 消息重试
- Token 过期静默踢出
- 微信小程序上线（~8 工时）

**P2 交付后可迭代：**
- 问卷调查端到端打通（表/API 完整）
- 笔记功能前端入口
- 教师端批量操作
- 测试覆盖缺口
- 审计日志前端页面
- 邮件通知

## 未实现的探索方向

以下为概念阶段方向，尚未进入设计：

| 方向 | 描述 | 与当前系统差距 | 优先级建议 |
|------|------|---------------|-----------|
| **A. 生理模拟引擎** | 时间-参数曲线模拟生命体征（HR/BP/SpO2 等），护理操作可揭露/改写 | 体格检查插件已建，但揭示的是静态预设值而非动态模型 | 低 — 需医护领域知识校准，建议外包后作为二期 |
| **B. 病人状态机** | 病情阶段流转（稳定→恶化→危重），受干预影响 | 无任何代码 | 低 — 依赖 A 的基础 |
| **C. 情感/态度深度模型** | 焦虑/配合度/健康素养动态变化 | 2D 情感模型已实现，可在此基础增强 | 中 — 提示词工程可做增量改进 |
| **D. 动态可视化** | 面部表情 + 监护仪面板 | 患者画像插件已建，但头像固定 | 低 — 纯表现层 |
| **E. 护理记录书写训练** | SOAP 模板 + AI 文书评分 | 护理记录已实现（HIS 风格而非 SOAP），文书评分未做 | 中 — 护理教育刚需，增量开发 |
