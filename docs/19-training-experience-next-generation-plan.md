## 一、决策与交付边界

### 1.1 产品定位

面向已学习基础护理评估、需要从“知道该问什么”过渡到“能够根据患者回答继续评估”的护理学生，提供可重复、有情境差异、能依据过程证据复盘的虚拟患者训练。项目仍是**实验性、体验优先、单人维护**；不以产品化规模、兼容旧构想或安全合规扩张为目标。审计和版本记录用于规范化、解释结果与科研跟踪。

下一批次主题：**从完整问诊，走向有依据的护理评估**。

```text
了解任务与辅助程度
  → 采集必要信息 / 查体
  → 根据患者回答追问与澄清
  → 整理事实、推测与未确认信息
  → 提交有依据的护理评估
  → 获得逐项证据、明确来源的评分与教师意见
  → 解释一次关键选择
  → 同病例纠正练习 / 新变式迁移练习
```

这是学生的学习过程，不是强制顺序状态机。对话、查体、记录可以往返；不要求学生按固定台词或固定提问顺序过关。

### 1.2 本批次交付

- 继续深化 `history_taking`，不新增 workflow、不重写技术栈。
- 选三个代表性病例家族，每个包含一个练习病例与一个迁移变式，共六个经教师审阅的情境；先做深，不追求病例数量。
- 完成病例、响应性互动、评分校准、复盘、重练/迁移的全链；同时修复直接损害训练可信度的现存断点。
- 内部按 W0–W6 的依赖推进，验收后**一个完整批次交付**，不把半条闭环拆成多次学生可见发布。
- 既有问诊病例仍可访问；新教学蓝图是本批次选定病例的能力，不得宣称所有存量病例已经校准。

### 1.3 明确不做

- 不开放独立 `clinical_reasoning` 学生端；不把 `simulations` 引擎嵌入问诊，去向见 [18](18-clinical-reasoning-disposition.md)。
- 不加入动态病程、干预执行、资源调度、完整 SBAR—复评阶段链；“根据证据调整评估”不等于“模拟行动后果”。
- 不以提问次数配额、随机拒答、倒计时加压或共情关键词解锁制造难度。
- 不以视频患者、更多表情、全新实时语音链路作为本批次创新主体；已有语音故障提示属于可信链路修复。
- 不建立通用教学编排器、评分插件平台、通用证据平台、独立成绩系统或在线调分后台。
- 不扩张外围列表、排行榜和大型教师分析台；只修改本闭环实际消费的界面与统计。
- 不设“必须出现多少优秀”的分布目标，不曲线调分凑比例，不把未经验证的 AI 总分用作独立高风险考核结论。

## 二、现状证据与尚未成立的结论

### 2.1 已知产品现象

维护者报告：**历史学生从未拿过优秀，评分判例较严格，硬编码数字分与等第存在问题。**这是本次校准工作的输入，不要求维护者重复证明，也不以重新查询“有没有优秀”作为调查目标。

这不能直接推出学生能力低，也不能直接推出所有低分都错。需要分开检查教学任务、条目判例、评分输入、分母、展示换算、等第解释六个环节。

## 三、教学和病例契约

### 3.1 标准化什么，不标准化什么

| 层次 | 必须明确 | 允许变化 |
|---|---|---|
| 必要责任 | 病例要求获得的关键信息、风险核实、记录真实性 | 信息已由患者主动提供时，可确认整合，不要求换句式重问 |
| 交流路径 | 是否理解并回应患者、是否针对线索推进 | 提问顺序、自然措辞、开放与聚焦的合理转换 |
| 证据整合 | 区分事实、推测、未确认；结论与证据相符 | 合理的记录表达与不同但有依据的优先级解释 |

不得用“患者更开心”替代专业沟通评价；必要的敏感问题可能引发不适。模拟情绪轨迹可辅助复盘，但不是学生能力或真实心理因果的证明。

### 3.2 病例教学蓝图（拟新增内容契约，非当前已支持字段）

在现有病例作者面和 `CaseRevision` 内容中承载，不另建病例系统。每个选定病例需具备：

1. 学习目标与前置能力；此次能评什么、不能评什么。
2. 稳定的核心事实与事实标识；初始可得、经合理提问可得、通过查体可得的来源。
3. 关键线索及其评估意义，允许的等价获取路径；不是一张必须依次触发的对话树。
4. 必须覆盖项、情境相关项与关键遗漏的区分；不适用由病例/任务预先声明，不交给评分模型随意缩小分母。
5. 可接受的证据整合与典型错误；明确“没有观察到干预结果”时应提出如何评价，而不是编造已有效。
6. 练习病例—迁移变式关系及共享目标。变式改变线索表达/位置或相关背景，不只改姓名与年龄。
7. 对应评分项和审阅记录。临床事实、关键项、等第判例由护理教师审阅；开发者不能代替临床裁定。

首批三个家族分别突出线索追问、患者顾虑与澄清、证据整合；每个仍需满足完整评估的基本要求，不把其他能力删掉。具体病种由现有病例适配度和教师审阅决定，不凭产品文档编造临床事实。

### 3.3 引导和患者行为

- 复用现有 guided / assessment 的辅助差异；不新增模式注册平台。盲盒只是选例方式，不自动等于某个能力等级。
- 引导给“还需弄清的领域及其意义”，不给唯一问句；独立练习减少即时提示，但病例事实和评价目标不暗中改变。
- 患者自然表达可以变化，核心事实必须稳定；合理等价问法应能获得相应信息，不以讨好关键词解锁。
- 有效行为差异应在后续信息澄清和复盘中可解释；不以不可预测的拒答、情绪跃迁增加难度。
- 教学蓝图只把当前患者应知道的内容送入患者上下文；参考答案、评分锚点、变式答案不泄露到学生对话。

## 四、评分重构方向：先定义证据意义，再定义等第

### 4.1 四层分离

```text
可观察行为与证据（包括未观察到 / 不适用 / 系统缺失）
  → 条目锚点判定与原始量尺
  → 必要时换算为展示分
  → 经校准的能力解释与等第
```

本批次不预先把 0–2 改为 0–3 或百分制逐项评分；先使现有锚点可见、可执行、可校准。**“部分完成”映射为 50 分只是算术，不天然等于不及格。**也不把所有硬编码数字当缺陷：问题在于数字是否有教学解释、唯一来源和适用范围。

### 4.2 必须落地的改变

1. **锚点送达**：评分输入必须包含每个适用条目的行为锚点、任务边界与已提交证据；生成标题、schema、实际量尺一致。禁止仍只发条目名称却声称行为评分已经生效。
2. **目标适配**：保留必要覆盖、响应性沟通、证据整合三个评价面。复核护理记录中的 ADPIE/措施效果要求：没有实际行动和复评机会时，评价的是计划与评价方法，不奖励编造结局，也不因无法观察而扣分。
3. **得分与失分都给依据**：有得分应引用支持证据；声称漏问或错误应说明要求、相关上下文及为何不足。文本长度不作为证据有效性的替代指标；简洁有效表达不能因不足十字被判无效。
4. **区分原因**：学生应做未做、任务不适用、证据不足、系统传输/生成失败分开处理。系统缺证不能清零后当作正常成绩；关键遗漏单独呈现，不能靠其他维度补偿后消失。
5. **取消凑反馈**：不足、漏问允许为空且有明确语义；不要求至少两条，不以强制字数或固定“肯定+不足”结构制造问题。同步改提示词、schema、验证、重试条件和前端空态，不能只改 prompt。
6. **保留原始精度**：新结果保留原始逐项分、逐项量尺和原始总分；展示换算与取整仅作投影。教师复核原始条目，不从取整后的展示项反推；不改条目直接提交复核必须保持总分不变。
7. **总分来源明确**：AI 初评、教师复核、系统异常分别可见；复核优先的有效成绩继续由现有单一口径消费。AI 与教师意见分开保存，不覆盖原判据。
8. **等第不在页面各算**：能力标签与阈值由一份服务端、版本化的评价政策定义，适用到明确任务/量尺/辅助条件。学生页、教师页、导出、筛选共同消费；数值分桶可保留为数值描述，但不得偷换成能力结论。
9. **未校准则不授予能力标签**：新流程在校准通过前只显示量尺、逐项表现和“尚未校准能力等第”，不把 60/85/90 自动解释成合格/优秀。既有历史标签如保留，仅标为旧规则结果，不重新解释学生能力。

### 4.3 校准方法与准入

- W0 建立去标识判例集：历史完整记录、教师编写的控制对照、边界与优秀表现参考；覆盖不同辅助程度、病例和缺失情形。
- 护理教师先按任务评判，再看 AI 分与原标签（**单人即可**；不要求多位教师联合宣判或一致性统计——维护者裁定该目标在产品上用不着）。当前没有这样的判例集，不能以开发者直觉替代。
- 必须包含：机械覆盖 vs 合理追问、漂亮共情但遗漏关键内容、简洁有效 vs 冗长重复、患者主动提供信息、合理不确定性、无干预结果可观察、真实无不足、系统缺证。
- 标定“完成/部分完成”的可观察行为与等级边界，允许多条合理路径；不先定优秀比例再倒推阈值。
- 开发判例与留出判例分开；同一组代表性输入重复评分，观察条目判定、关键遗漏、等第的稳定性；阈值附近单独检查，不只看总分均值。
- 评估 AI—教师分歧、关键遗漏漏判、原始分到等级的对应关系（**不评估教师间一致性**）。数值准入标准由教师在看留出集结果前定下并记录，禁止见结果后降低标准。
- 若暂无教师校准资源：代码侧可完成证据、可信链路和复盘，但**不能声称完成校准或发布经认证的能力等第**。形成性反馈与教学有效性声明分开。

### 4.4 版本、历史与研究

- 当前 `rubric_version` 标识复用已经不能区分历史量尺。新记录需关联准确的 rubric 内容身份、适用项与分母、评分提示词内容身份、模型身份、展示映射身份、等第政策身份及辅助条件；内容身份依 [17](17-training-identity-and-state-contract.md) 派生优先，不为每个名字新建表。
- `prompt_schema_version` 不是评分规则版本；`mapping_version` 不是能力等第政策版本。不得复用字段偷换含义。
- 同一个 `id@version` 下修改锚点/量尺不再被允许作为正式发布策略；新版本和内容摘要必须能够定位实际规则。保存患者 prompt 不等于保存了评分 prompt。
- 历史分不覆盖、不批量提分、不从展示分伪造原始分；快照缺失/身份不明的记录明确标为不可比。
- 历史研究重评只能另存为实验评估，保留原结果和来源，不通过线上“重试评分”覆盖正式成绩。本批次不新建通用重评实验平台。
- 趋势和班级统计按可比组呈现：任务目标、病例家族/经验证可比情境、rubric 内容、辅助条件、评分/等第政策须明确；不同原始满分线性转成 100 分不代表可比。
- 本批次不做跨量尺等值换算。相同病例熟悉效应、变式迁移表现与版本变更效应分别解释；不能只凭前后均分宣布教学有效。

数据/API 的最小语义要求（实现时落入现有模型并生成 API 类型，不手改 `.gen.ts`）：

- 新评分项携带稳定 item 标识、原始分及上限、证据引用、判定理由、适用/缺失状态；展示分与等第单独投影。
- 证据引用应能定位到已存在的 Message、TrainingAction 或提交产物字段；无依据时标为无法判断，不把自由文本中的“第几轮”当可靠主键。
- 新反馈计划只给少量最重要的目标：关联评分项、证据、原因、下一步练习原则；不是另一套脱离评分的教练结论。
- 新练习记录标明源练习与练习目的（同例纠正/迁移），由服务端解析允许的目标病例；同例需明确原 revision 是否仍允许开始，不可悄悄换成最新版本却声称相同任务。
- 现有作业次数、受众、病例归档与可开始门禁继续生效。自由重练不得计入作业成绩或绕过次数限制；没有可用变式时不渲染虚假的入口。
- 新旧结果读取只保留解释历史数据所需的分支，不维持两套新评分写入路径；不能借“干净切换”删除历史证据。

## 六、工作包与依赖

### W0 基线与教师校准判例

**输入**：本文件第二节的已知现象、只读历史数据、现有 rubric/患者/评分输入。

**交付**：三个病例家族的目标边界、去标识判例集、评分链路基线、可比性分组规则、教师审阅记录与预先确定的验收规则。先确认任务到底提供哪些表现机会，再判断判例是否过严。

**通过条件**：每个核心目标有正例、反例和边界例；原始量尺/分母/规则身份可查；不把单回合或系统缺证记录混作完整能力判例。缺少教师输入时明确阻断等级校准，不阻断技术修复。

### W1 核心训练可信链路

**交付**：学生可见教师复核；pending 自动查询到终态；GET 刷新与 POST 重评分分离；不确定进度不造百分比；真实保存回执；计时/暂离/断线提示与后端状态一致；学生个人结果不借用全体排名权限。

**通过条件**：学生提交后离开再返回可收到结果；评分失败可自助恢复且不会误触重评；保存失败不显示已保存；离页请求失败时不承诺已暂停。WS 故障不被描述成 HTTP 工具全部不可用；语音降级可见。

### W2 病例教学蓝图与迁移变式

**依赖**：W0 的目标与病例审阅。

**交付**：六个情境的蓝图、家族/变式关系、关键线索与合理路径、适用评分项；既有作者表单/校验器/发布链同步支持。

**通过条件**：每项关键证据有合理获取途径；目标与评分对应；不能发生作者保存了字段而运行时从不消费；参考答案不泄露。存量病例不被默认为已校准。

### W3 响应性互动与引导撤除

**依赖**：W2；复用现有 patient/context 管线。

**交付**：基于稳定事实的患者回应、按已有模式提供的提示、对已获得信息的认可、关键线索的后续响应。

**通过条件**：等价问法获得相应信息；患者主动告知后不要求机械重问；重复运行核心事实不变；学生可以选择不同合理顺序；不以情绪值或关键词充当答案门锁。

### W4 评分证据、标度与等第校准

**依赖**：W0；病例适用性依赖 W2。不得等 UI 完成后才处理量尺。

**交付**：第四节所有改变，包括锚点送达、真实证据、原始精度、空反馈、复核一致性、政策身份、历史解释与所有成绩消费方的口径切换。

**通过条件**：教师确认的优秀参考表现能够按校准政策被识别，关键遗漏参考例不被漂亮话补偿掩盖；不是要求历史样本固定比例优秀。留出判例、重复评分与边界检查满足 W0 预定标准；未通过时不得开启能力等第。

### W5 复盘—重练—迁移闭环

**依赖**：W1/W2/W3/W4 的可用结果。

**交付**：结果页首先解释少量关键选择，支持回到具体证据；原则与示例而非唯一标准话术；教师复核可见；同例纠正和变式迁移分别进入真实可开始训练。

**通过条件**：学生能找到“当时信息—自己的行为—评价理由—下次原则”；入口遵守病例/作业限制；同例熟悉改善不伪装成迁移；证据不足时不生成确定性指导。

### W6 端到端验收与整批切换

**依赖**：W0–W5。

**交付**：开发和留出判例结果、教师分歧记录、学生/教师浏览器验收、变更后的契约与历史口径说明；完成后一个批次交付。实际提交、发布仍需维护者明确授权，本计划本身不授权部署。

**通过条件**：下节的功能与教学验收均有对应证据。不能用编译通过、按钮可点或平均分升高替代学习闭环验收。

## 七、验收矩阵与发布判据

| 场景 | 要观察的结果 | 验证层 |
|---|---|---|
| 覆盖近似，机械逐项问 vs 按回答追问 | 响应性维度能依据证据区分，不靠字数 | 教师盲评 + 真实评分对照 |
| 安抚话术丰富但关键内容遗漏 | 关键缺口独立可见，不被总分掩盖 | 教师判例 + 结果页 |
| 简洁有效 vs 冗长重复 | 不因表达短或回合少而天然失分 | 真实患者/评分对照 |
| 患者主动提供信息 | 合理确认与整合获得认可，无重复提问奖励 | 对话回放 + 条目判定 |
| 无干预结果可观察 | 正确承认未知并提出评价方法，不要求编造效果 | 产物判例 |
| 无明确不足或漏问 | 反馈可为空并解释其含义，不触发补全重试凑数 | 提示词/校验逻辑 + 真实评分 |
| 系统丢失证据或评分降级 | 显示异常，不把缺证转为学生 0 分进入统计 | 故障场景 + API/界面 |
| 原始项未改的教师复核 | 原始分、展示总分保持一致，AI/教师来源可辨 | 回归用例 + 教师浏览器 |
| 两种量尺同为百分制 | 不直接混算能力趋势或套用同一等第 | API/统计/导出 |
| 评分中离页后回到详情 | 自动到达终态，刷新不重评，失败有真实重试入口 | 学生浏览器 |
| 同例与变式再次开始 | 记录目的和来源可查，作业次数不被绕过 | API + 学生浏览器 |
| 旧记录无原始分/身份不明 | 原结果保留，不静默重算或伪造等第依据 | 历史回放 |

验证顺序：现有相关回归 → 真实患者和评分场景 → 学生/教师实际界面 → 教师判例与留出集复核。LLM 实验与部署环境严格分开；不拿生产学生记录触发覆盖式重评来测试。

效果关注：学生能否解释一次关键选择、能否在未见变式中识别同类线索、教师是否认可反馈证据。完成率、满意度、均分和优秀率只作辅助描述；本批次不以小样本或版本前后均分宣称临床迁移已被证实。
