# 临床推理模拟实验：保留素材说明

> 状态：冻结，不是实施计划（2026-09-27）。原 MVP-A/MVP-B 执行说明、范围指令、步骤、验收脚本与后续扩展要求已删除；详细设计可从 Git 历史回溯。
> 正式去向由 [18](../18-clinical-reasoning-disposition.md) 决定；正式训练下一批次只按 [19](../19-training-experience-next-generation-plan.md) 实施。

## 保留什么

现有 `backend/modules/simulations/` 与 `frontend/src/simulations/` 是独立实验资产，包括回合/时间推进、检查与结果、病程状态及行动后果等机制。当前资产和接口边界以 18 的代码清单为准，不用早期单病例设计描述当前实现。

可参考的设计问题是：不同动作如何消耗时间、证据何时可见、行动如何影响后续状态。它们不是正式护理评估训练必须接入的功能，更不证明该模拟器已具有教学效度。

## 不再做什么

- 不按旧 brief 继续实现或扩展生理引擎、药物、病例目录、会诊或阶段链。
- 不把实验病例迁入正式 `CaseRevision` 作为本批次任务。
- 不将模拟器接入学生作业、正式评分和教师复核。
- 不因保留这份历史入口而自动重启第二工作流；重启必须满足 18 的独立教学目标、维护与校准条件。

本次仅删除过时文档内容，没有删除实验代码、路由或历史数据。
