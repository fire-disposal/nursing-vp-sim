# 下一阶段：把"问诊练习"变成"会变的情境"

> 2026-09-27。原型阶段以**体验与展示价值**优先（稳健性不是本阶段的证明目标）。

**已有燃料**（这也是为什么现在做这些便宜）：流式 TTS（句子级 PCM 分块 + `abort`）、情绪状态与事件时间线、
患者主动（initiative）、表现层策略链（`video → realistic → static`）、场景是数据（`scene.vitals` 可随时更新）、
教材索引（3 本 / 76 章）、发布器骨架（修订 / 指纹 / 批次 / 问卷）。

| 方向 | demo 里长什么样 | 最小切片 |
|---|---|---|
| **1 会变的病程** | 8 分钟内 SpO₂ 94→88，患者开始催问"我怎么越来越闷" | 场景时间线：每 N 轮更新 `scene.vitals` + 一条可见体征，前端显式呈现 |
| **2 多人戏** | 母亲替患儿回答 / 医生护士交接 / 家属意见冲突 | 病例声明 2 个在场者（各自可见与隐藏事实）+ 对话路由到"正在说话的人" |
| **3 在场感** | 一句"您别急"之后，呼吸频率与音色肉眼耳听地缓下来 | 三组视觉：说话态 / 情绪态 / 生理态，由现有情绪与体征驱动 |
| **4 双工对谈** | 中途打断"等一下，您刚才说…"，患者停下并回答 | 持续拾音 + 端点检测 + 打断（停播 + `abort` + 取消在途）+ 首音 < 1s |
| **5 后果** | 跳过手卫生，患者直接说"你先洗手吧" | 病例声明少量"失当触发 → 患者反应"，用隐藏事实 + 情绪联动表达 |
| **6 用对话造场景** | 一句话描述，10 秒后得到场景卡草案 + 三条待确认项 | 自然语言 → 病例草案 → 现有发布门禁 → 教师确认 |

**顺序**：`3 + 4`（体验立竿见影且互相增强，服务器端已就绪）→ `1`（时间压力，架构不改）→ `6 + 变体发布`（平台感）。
`2` / `5` 可在任意阶段插入，它们是数据与提示层的小扩展。
