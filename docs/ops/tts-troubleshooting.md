# TTS / ASR 语音服务排障

> 当训练页患者不发声、语音识别失败时，逐层排查。

## 快速诊断

```bash
# 检测后端健康
ssh yecaoyun "curl -sf http://127.0.0.1:9001/api/health"

# 查看 TTS 相关日志
ssh yecaoyun "docker logs nursing-vp-sim-backend-1 --tail 50 2>&1 | grep -iE 'tts|asr|volc|voice'"

# 测试连通性
ssh yecaoyun "curl -sf 'http://127.0.0.1:9001/api/admin/voice/test?service=tts'"
```

## 字幕与语音的口径

患者回复里的**括号旁白**（`（叹气）`、`（皱眉按着下腹）`、`（沉默几秒）`）只出现在字幕里，
不进 TTS：字幕保留神态/动作，学生看得到；朗读只读台词。判定在 `engine/tts/segmenter` 的切片阶段，
跨 chunk、跨句都成立，括号内的句号也不参与断句（`（沉默。几秒）` 不会把一句话切成两段）。

口径与边界：

- 情绪的音色由**情绪状态**驱动（TTS 请求带当前情绪），不靠把旁白念出来；
- 对白里用括号做的补充说明（如药名 `（阿仑膦酸钠）`）同样不会被读出——这是刻意的取舍：
  旁白与台词没有可靠区分手段，宁可少读一句注释，也不念出「叹气」；
- 括号未收尾（模型截断）时：中途出现且明显过长 → 当台词说，避免吞掉后半段回复；
  回复结束时仍未收尾 → 丢弃残旁白，保留它前面已说出口的内容。

## 排查链路

```
学生端听不到语音
  → 训练页 TTS 开关是否开启？（右上角按钮）
  → 管理后台 → 语音服务 → App ID / Token 是否已配置？
      → 否 → 火山引擎控制台获取 → 填入
  → 点击"测试 TTS"是否通过？
      → 否 → 检查火山引擎余额/配额/Token 过期
  → 前端已显示黄色降级指示灯？
      → 预算耗尽或熔断中，系统已自动切浏览器 TTS 兜底
```

## 常见问题

| 现象 | 原因 | 操作 |
|------|------|------|
| 语音变成浏览器机械音 | 预算 ≥ 100% 或熔断 | 正常降级，无需干预；检查管理后台调高预算 |
| 语音识别不准 | 噪音 / 网络 / 采样率 | 安静环境使用，管理后台降低 ASR 采样率到 8000 |
| ASR 报 401 | Token 过期 | 火山引擎控制台重新生成 Access Token → 填入 |
| TTS 报 connection refused | 火山引擎服务异常 | 等待恢复（前端自动切换浏览器兜底） |

## 密钥配置位置

- **TTS/ASR Token**：管理后台 → 成本管理 → 语音服务 Tab
- **LLM API Key**：管理后台 → 成本管理 → LLM API Tab
- **后端兜底**：`.env` 中的 `DEEPSEEK_API_KEY`

## 熔断机制

连续 3 次调用失败 → 熔断器打开 5 分钟 → 前端自动降级浏览器 TTS。
熔断恢复后自动切回火山音色，无需人工干预。
