# 写实风格病人头像替换方案

## 1. 背景与目标

当前训练系统已暂时停用基于情绪切换的人像变体，训练过程中使用按年龄和性别匹配的静态 PNG 头像。

论文截图需要更高级、更接近真实临床场景的视觉效果，因此计划为论文展示病例引入一张**病例专属、静态、合成写实人像**，同时保持训练逻辑和情绪状态逻辑不变。

目标：

- 提升训练页面的临床真实感和论文截图质量；
- 保证同一病例在欢迎页、对话区和训练结果区使用一致的人像；
- 避免真实患者的隐私、肖像权和授权风险；
- 暂时不恢复动态换脸或情绪头像变体；
- 不影响其他病例和现有训练流程。

## 2. 推荐方案

### 2.1 使用病例专属的虚构人像

为论文展示病例固定一组病例信息，并根据该病例生成一张完全虚构的写实人像。

示例：

- 姓名：王建国
- 年龄：68 岁
- 性别：男
- 训练主题：胸痛问诊
- 场景：病房床旁
- 表情：自然、略显不适，但不过度夸张
- 构图：胸像或半身像，正面或 3/4 侧脸
- 服装：简洁病号服
- 背景：低干扰病房环境，或使用统一的浅色背景

病例信息、头像年龄、性别、服装和临床场景必须保持一致，避免出现“病例是老年男性但头像明显为年轻人”等不协调情况。

### 2.2 图片来源

优先级如下：

1. 使用 AI 生成完全虚构的人像；
2. 使用具有明确商业、学术和论文展示授权的图库图片；
3. 使用真实患者照片，仅限已经取得书面知情同意、肖像授权并完成必要伦理审批的情况。

禁止直接从互联网下载未确认授权的真人照片，也不应使用可识别真实患者身份的照片作为系统头像。

## 3. 图片规格

建议准备一张高分辨率 PNG：

- 文件格式：PNG；
- 推荐尺寸：`1536 × 1536`，最低不低于 `1024 × 1024`；
- 构图：胸像或半身像；
- 人物脸部不要贴近边缘，保留裁剪空间；
- 光线：柔和、自然、统一；
- 色彩：自然肤色、低饱和、医疗环境色调；
- 背景：简洁、低干扰，避免影响头像识别；
- 不包含品牌 Logo、医院名称、患者住址或其他敏感信息。

需要重点检查并避免：

- AI 生成的五官、耳朵、眼镜或衣物异常；
- 过度磨皮或明显商业广告风格；
- 夸张痛苦表情；
- 与病例年龄、性别不符的人像；
- 图片来源和授权无法追溯。

## 4. 头像表现策略

### 4.1 固定头像

论文展示病例使用一张固定 PNG。进入训练、刷新页面或发生情绪变化时，人物不更换、不变脸。

训练中的情绪变化通过以下内容表达：

- 患者对话内容；
- 情绪状态文字；
- 信任度、焦虑度、合作度等指标；
- 轻量级边框或状态标签。

不建议使用多张写实头像频繁表示情绪变化。频繁切图会降低页面稳定性，也会让论文截图难以保持一致。

### 4.2 资源命名

建议新增资源：

```text
frontend/src/assets/avatars/case-chest-pain-elder-male.png
```

如果后续增加其他论文病例，使用病例语义命名，例如：

```text
case-fever-middle-female.png
case-fall-elder-female.png
```

## 5. 实现方案

当前代码已经将动态头像切换逻辑暂时注释，保留后续恢复能力。

固定头像的使用链路保持为：

```text
病例信息
  → getPatientAvatar(patient)
  → 固定 PNG
  → 欢迎页、聊天区、训练结果区
```

建议按以下方式接入病例专属头像：

1. 将获得授权的 PNG 放入 `frontend/src/assets/avatars/`；
2. 在头像资源映射中增加该资源；
3. 仅为论文展示病例配置专属头像；
4. 其他病例继续使用现有按年龄和性别选择的默认头像；
5. 保留 `patient-portrait.ts` 和情绪头像切换代码，但不在当前版本启用；
6. 不修改情绪状态、信任度、焦虑度和评分逻辑。

## 6. 论文截图前检查清单

### 视觉一致性

- [ ] 欢迎页头像与聊天区头像一致；
- [ ] 训练中情绪变化不会更换人物；
- [ ] 训练结果页仍显示同一病例头像；
- [ ] 病例年龄、性别、服装和头像一致；
- [ ] 图片在论文截图尺寸下五官清晰；
- [ ] 页面没有明显加载闪烁或图片替换。

### 合规与可追溯性

- [ ] 图片来源已记录；
- [ ] AI 生成提示词或图库授权信息已保存；
- [ ] 确认图片不对应可识别的真实患者；
- [ ] 不包含真实患者姓名、住址、住院号等敏感信息；
- [ ] 如使用真人照片，已完成书面授权和伦理审批。

### 工程验证

- [ ] 前端 TypeScript 检查通过；
- [ ] 头像相关测试通过；
- [ ] 刷新训练页面后头像仍能正确加载；
- [ ] 不同年龄和性别病例不会错误使用论文专属头像；
- [ ] 图片路径经过 Vite 构建后仍可正常访问。

## 7. 推荐落地结论

本项目采用以下落地方式：

> 为论文展示病例生成一张完全虚构的、高分辨率老年男性病房胸像 PNG，作为该病例的固定头像；动态情绪换脸继续停用，情绪变化通过对话和状态指标表达。

该方案改动范围小、截图稳定、视觉上更接近真实临床场景，也能最大限度降低真实患者隐私和图片授权风险。
