## 发布授权与路径

本次文档变更不授权发布。维护者明确授权后，按仓库既有路径执行：完成代码与验证 → 推送 master → `pnpm run tag` → tag 触发部署。

当前 `production` 未配置 Required reviewers，**推 tag 即发版，没有人工审批等待**。不能把“没有平台审批”理解为“不需要维护者授权”。操作与回滚入口见 [运维指南](../09-operations.md)、[单实例迁移](../ops/single-instance-migration.md)。

## 五类证据

| 检查 | 发布前应有证据 |
|---|---|
| 功能与研究边界 | 学生/教师实际界面完成任务；19 当前切片的通过条件有结果；未校准能力等第不得声称已校准，U0 不得写成教学效果 |
| 评分与历史 | 原始量尺/展示/复核来源清楚；降级可见；无静默历史重算；不使用优秀比例作为放行指标 |
| 运行与恢复 | 作业、评分与对话失败有真实状态和恢复路径；使用已确认指向隔离环境的本地栈验证写操作，不让代理脚本误连生产 |
| 成本与健康 | 使用当前只读诊断与调用记录检查异常；记录部署版本、告警与判断依据，不套用旧固定基线或过时字段 |
| 备份与回滚 | 按现行运维规程确认备份可用、迁移影响与回滚目标；不能把“有备份文件”写成“恢复演练已通过” |

诊断字段与鉴权以 [诊断契约](../ops/diagnostics.md) 为准，备份恢复以 [现行规程](../ops/backup-restore.md) 为准。不得在记录中输出数据库连接串或 token。
