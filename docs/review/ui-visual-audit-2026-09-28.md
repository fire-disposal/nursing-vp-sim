# UI 视觉审计（2026-09-28，生产环境实测）

> 方法：以学生账号在生产 `https://iomt.205716.xyz` 逐页截图（亮色主题为主），并用 DOM 度量取客观数据；
> 暗色侧以维护者提供的截图为对照。**结论按严重度排序，每条给出证据与归属**。
> 本文只记录事实与判断，不改代码；修复归属见 §五。

## 一、跨页共通问题（不是情境轨独有）

| # | 现象 | 证据（2026-09-28 生产实测） | 影响 |
|---|---|---|---|
| C1 | **圆角无处不在** | 各页「圆角 > 6px 的可见元素」计数：`/qa` 48、`/history` 40、`/training` 34、`/profile` 22、`/scenario` 12 | 全站观感偏软、缺"干练锐利"（维护者明确要求） |
| C2 | **页面级滚动普遍存在** | `/training` 内容高 1315 vs 视口 833；`/history` 1327 vs 833（溢出约 480–500px） | 学生日常页需要滚动才能看完；与"大卡片/大留白"叠加后更明显 |
| C3 | **字号刻度不一致** | 同页可见字号跨度 `12–26px`（`/training`）、`12–22px`（`/history`、`/qa`、`/profile`）；`/history` 中位数仅 **12px** | 层级靠"大小跳跃"而非系统刻度，扫读成本高 |
| C4 | **作者态/系统态信息混入学生面** | 情境入口页每张卡片显示 `experimental` 徽章与 `修订 N` | 学生看到的是编辑态字段；与"不要将用户当傻子"同源 |
| C5 | **说明文本代替设计** | 情境入口页顶部三行作者自述；右栏曾出现"它只会因为你做了什么而增长，不需要你填写。" | 破坏沉浸、增加阅读噪声 |

## 二、情境训练（学生面）

### 2.1 会话页：旁白被压成单字竖列（**P0，生产正在发生**）
- 证据：`.sc-subtitle` 实测 **宽 27px × 高 1336px**，而对话框 `.sc-lines` 为 908×250；整块面板 95% 为空。
- 影响：主阅读区 60% 的空间被一个不可读的塌陷列占据（维护者截图同证）。
- 归属：情境轨（重做中；本地工作树已不复现，将在本轮发版一并验证）。

### 2.2 会话页：主次颠倒与信息重复（**P1**）
- 场景块 ~595px 高把动作区压到视口下缘；页面总高 1106 > 视口 833。
- 同一份信息多处出现：护士电话报告同时出现在 ①左下「现场线索」卡片 ②右栏「线索板·电话里听到的」 ③「已确认的」。
- 无意义卡片：「可作动作 9」（只有一个计数）；空面板带占位句「经历时间线 · 第 0 回合 · 还没有动作」。
- 层级荒谬：全屏最大字号曾是右栏的「0 次」（医嘱数）。
- 归属：情境轨（重做中）。

### 2.3 会话页：动作区像仪表盘（**P1**）
- 默认态可见按钮 **18 个**（DM 选项 + 全部 affordance + 自由输入控件），分区标题「此刻值得做的 / 这里能做的事」暴露了"菜单"本质。
- 维护者判断：动词表不重要，**自由表达 + DM 主持**才对；菜单式陈列等于把交互降级成仪表盘。
- 归属：情境轨（重做中）。

### 2.4 入口页（`/scenario`）（**P2**）
- 卡片：内容约 120px 却占 ~180px（底部死白），圆角约 10px，首卡标题折两行导致同排 meta 错位。
- 经历区：三条全显「进行中」（会话只有显式结束才结算），行高 ~74px 仅承载一行标题 + 一行状态；右侧只有时间戳，缺「第 N 回合」。
- 归属：情境轨（重做中）。

## 三、非情境页（学生日常面）

- `/training`：卡片数量多（9 张大卡）+ 内容 1315px，需滚动；字号跨度 12–26px。
- `/history`：中位字号 12px、列表密度偏低、内容 1327px，与 `/training` 同样是"大卡片 + 长页面"。
- `/qa`、`/profile`：无页面级滚动（好），但仍是宽字号跨度 + 大量圆角元素。
- 归属：**老系统页面**，本轮不动；若要统一"干练锐利"，属于**主题级**决策（见 §四）。

## 四、需要维护者决策的一条（主题级）

C1（圆角滥用）在非情境页面同样成立（每页 22–48 个 > 6px 圆角的可见元素），说明它来自 **Mantine 主题默认值**而非某个页面写错。
可选：
- **(a) 保持现状**：只把情境轨改成 0–2px 直角（本轮已按此执行），全站不动；
- **(b) 主题级收紧**：在 Mantine 主题里把默认圆角降到 `sm/xs`，全站一次性变"锐利"，代价是所有页面的观感同时变化、需要一轮回归看图；
- **(c) 分页推进**：先主题级降一档，再逐页看图微调。
