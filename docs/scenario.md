# 情境训练 · V3 核心构想（概念资产，无运行时）

本轨是 **V3 动态世界**的构想留档，**当前没有后端运行时**：没有路由、没有 ORM 注册、没有开关、
没有 LLM 用途、没有运维面、没有权限位。平台不演绎这些病例，也不把它们并进训练/成绩/导出。

V1（`modules/training/**` 问诊训练）与 V2（`clinical_reasoning` 病例）**不受影响**，
本文只描述 V3 想要什么，以及仓库里为此保留了哪些材料。

## 想解决什么

一句话：**病情会变、行动有后果、时间有压力**。V1/V2 的病例都是"静态场景 + 问诊评分"，
判的是采集与表达；V3 要判的是**判断**——先做什么、什么时候升级、哪个动作是无效重复。

因此 V3 不扩展成另一套问诊或评分平台，只承担三件事：病情演化、行动后果、时间压力。

## 核心构想（概念，不在代码里）

1. **病例是声明，不是脚本**。病例只说清"现场有什么、谁能做什么、什么算采集到了、
   什么算做错了"，**不说**世界会怎么回应。回应由模型在工具循环里演绎——
   平台给边界（能写哪些键、什么能揭示、图要等哪条线索），模型在边界内演。
2. **平台管确定性，模型管世界**。学生点的动作改什么、揭示什么、花多少时间，由声明确定性地算；
   数值怎么变、谁进来、什么被看见，由模型用工具改，逐条校验，越界即拒。
3. **判读只读账本**。事实是否可观测 = 线索已揭示或动作已用过；判据只读这个账本，
   模型看不见也改不了判据、权重与真相。
4. **内容只有一份，没有修订系统**。没有修订号、没有形状版本、没有转换链——内容在写入时校验。
   可复现性靠"开局时快照当时内容"实现，而不是靠版本管理。
5. **读数归设备面板**。学生能看到的数值只走声明的设备通道；没有挂上通道的数值只存在于引擎内部。
6. **情境时间是累计值**。只有声明为耗时的动作与模型的时间推进会让它走；说话、观察、提问都不推进。
7. **表达形式是文件夹**：一个病例一个文件夹，`case.toml` 装机制、`case.md` 装散文、
   `img/` 装图片字节。TOML 与 MD 往返无损（逐字节 / 模型深相等）。

## 仓库里保留了什么

`backend/modules/scenario_training/` 只剩概念资产，**共 5 个 Python 文件 + 5 个病例文件夹**：

| 文件 | 作用 |
|---|---|
| `schema.py` | `ScenarioPack` 声明模型与封闭词表：动作类型 6 种、效果操作 3 种、触发子句 4 种、判读规则 6 种 |
| `validation.py` | 加载期**检查器**：引用闭合（线索/动作/事实/设备/状态键）、词表闭合、命名空间与边界合理性。只报问题，不改内容 |
| `case_folder.py` | 病例文件夹 ⇄ `ScenarioPack` 的无损往返，以及 zip 收发 |
| `standard_case.py` | 最小可校验病例模板（"病例格式长什么样"的活文档，带占位注释） |
| `__init__.py` | 包声明 |

`cases/` 下保留五个病例：`bp-contradiction`、`night-call-decision`、`sputum-ineffective`、
`triage-hidden-bleed`、`two-beds-priority`。

## 病例文件夹长什么样

```
cases/<key>/
  case.toml   机制与 meta：key/title/one_line、player、setting.cues、actors（含 knowledge）、
              affordances、state_keys/state_bounds、facts、criteria、devices、assets、failure
  case.md     散文四节：## 处境 / ## 人物（### <actor_id> 逐人一段）/ ## 真相 / ## 教师备注
  img/<file>  asset.file 指向的图片字节（不重编码）
```

拆分原则是**同一份事实一处落点**：TOML 只装机制与 meta，MD 只装散文。解析只按标题切块，
不做行内语法，因此往返无损。

## 校验器做什么、不做什么

- **做**：检查引用闭合（揭示了未知线索、引用了未知动作/事实/设备都会报）、
  未登记状态键、`state_bounds` 只约束数值键且区间有序、同一读数不在两台设备上重复、
  动作类型/规则参数与动作类型匹配、开场可见文案不泄底。
- **不做**：不判分数、不看图片字节是否已上传（不做 IO）、不改内容。
  它是**检查器**不是门禁——作者可以留待补的引用。

## 恢复 V3 时需要重新决定的事

这些都不是本文能定的，恢复运行时前必须单独决策：

- 模型侧权限边界（模型能改的世界键集合、工具集合与拒绝策略）。
- 时间语义（一个"情境时间单位"对应多少真实分钟、谁可以推进）。
- 判读是否进成绩（当前明确**不进**：未做法庭级判例校准）。
- 未测量读数必须显示为未知，不得用包内初值冒充已测。

## 已知边界

- 判读未经教师判例校准，**不作课程成绩**。
- 病例内容不是"可运行产品"，只是可读、可校验的材料。
- 五个病例覆盖病情恶化与优先级判断两个方向，不覆盖问诊评分（那是 V1/V2 的职责）。
