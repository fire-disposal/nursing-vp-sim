# Remove Fernet Encryption — Plaintext API Key Storage

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove Fernet symmetric encryption for API keys in `api_secrets` and `voice_configs` tables. Store keys as plaintext. Delete all Fernet infrastructure. Remove env fallback in `_select_config` (fail hard if no DB key available).

**Architecture:** Two DB tables hold API keys: `api_secrets` (LLM provider keys, encrypted with Fernet) and `voice_configs` (TTS provider key, also Fernet). Both get plaintext columns. The `encrypt_api_key`/`decrypt_api_key` functions and their module are deleted. The `_select_config` env-fallback path is removed — `ProfileRouter.select()` either returns a valid DB profile or raises. The `_SyntheticConfig` class is deleted.

**Tech Stack:** Python 3.13, SQLAlchemy, Alembic, PostgreSQL

## Global Constraints

- All `api_secrets.base_url` must default to `https://api.deepseek.com`
- VoiceConfig uses Volcengine TTS, not DeepSeek — keep its separate provider config
- No silent fallback: missing/invalid DB key → hard error, not env fallback
- Migration must be reversible (downgrade re-encrypts with FERNET_KEY from env)
- Remove `FERNET_KEY` from `.env.example` and `config.py` validation
- Update `tests/conftest.py` to remove FERNET_KEY
