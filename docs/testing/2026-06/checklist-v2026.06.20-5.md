# v2026.06.20-5 测试清单

**版本**: v2026.06.20-4 → v2026.06.20-5
**环境**: https://test.205716.xyz

### 1. 护理问答 — 教材参考开关
**操作**: 学生登录 → 进入「护理问答」→ 点击输入框左侧「教材」按钮开启教材参考 → 输入护理学相关问题并发送
**预期**: 回答下方出现可折叠的「参考教材」卡片，点击展开显示教材名称和章节

### 2. 教材参考开关反复切换
**操作**: 在同一会话中，先开启教材参考发送一条消息 → 关闭教材参考发送一条 → 再次开启发送一条
**预期**: 仅开启教材参考时发送的消息显示引用卡片，关闭时不显示；回答内容不受引用卡片影响

### 3. 护理问答 — 无教材参考模式
**操作**: 确认教材参考开关关闭 → 发送护理问题
**预期**: 正常返回回答，不显示引用卡片，回答速度不受影响
