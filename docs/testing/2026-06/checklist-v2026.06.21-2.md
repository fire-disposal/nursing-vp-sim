# v2026.06.21-2 测试清单

**版本**: v2026.06.21-1 → v2026.06.21-2
**环境**: https://test.205716.xyz

### 1. 学生自主训练配置
**操作**: 学生登录 → 点击「病例训练」→ 选择一个病例卡片 → 在弹窗中勾选「护理查体」、选择「进阶」、设置时长 → 点击「开始训练」
**预期**: 弹窗显示病例名称、难度星级、性别、年龄、主诉；配置面板三个区域可正常切换；时间滑块可拖动或点击±按钮；点击开始训练后正常进入对话页面

### 2. 评分完成通知
**操作**: 学生登录 → 开始训练并完成对话 → 点击「结束训练」→ 查看评分进度页面 → 点击「返回主页」→ 等待评分完成（约1-3分钟）
**预期**: 评分进度页出现"返回主页"按钮可正常回首页；返回主页后若评分完成，右上角弹出"评分已完成"提示，点击"查看"跳转到评分详情

### 3. 管理后台练习模板
**操作**: 管理员登录 → 进入管理后台「练习模板」→ 查看列表 → 点击新建或编辑
**预期**: 列表不再显示"模式"列；创建/编辑表单不再有"模式"下拉框；创建模板只需填写名称、病例、功能开关、时长和轮次

### 4. 训练中途功能开关
**操作**: 学生登录 → 开始训练 → 点击右上角齿轮图标 → 查看功能开关
**预期**: 功能开关弹窗仅显示「允许暂停计时」一项，其余功能开关不再显示
