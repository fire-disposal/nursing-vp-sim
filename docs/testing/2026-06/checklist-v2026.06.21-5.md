# v2026.06.21-5 测试清单

**版本**: v2026.06.20-4 → v2026.06.21-5
**环境**: https://test.205716.xyz

### 1. QA 教材参考 — 非流式
**操作**: 学生登录 → 进入「护理问答」→ 确认底部「教材」开关为开启状态 → 输入护理学问题（如"肺炎病人的护理措施有哪些"）→ 点击发送
**预期**: AI 回答中引用教材内容，可能出现"[来源: 内科护理学 > 呼吸系统疾病病人的护理]"等引用标记；回答下方出现「参考教材（N）」卡片，展开后列出引用来源

### 2. QA 教材参考 — 引用查看原文
**操作**: 在上一题的 AI 回答下方 → 展开「参考教材」卡片 → 点击任意一条引用来源
**预期**: 弹出整屏弹窗，显示教材名称、章节路径及完整章节正文内容；可点击关闭或点击背景关闭

### 3. QA 教材参考 — 流式
**操作**: 学生登录 → 进入「护理问答」→ 开启「教材」开关 → 输入问题（如"术后感染的预防措施"）→ 观察流式输出
**预期**: 流式逐字输出正常；回答完成后可见「参考教材」引用卡片和出处

### 4. QA 教材参考 — 追问
**操作**: 在上一题回答页面继续追问相关子问题 → 发送
**预期**: 开启教材增强时追问同样能检索教材；历史对话上下文正常保持；回答下方有引用卡片

### 5. QA 教材参考 — 关闭开关
**操作**: 点击底部「教材」按钮将其关闭（变为灰色）→ 输入问题 → 发送
**预期**: AI 正常回答，不依赖教材检索；回答下方无「参考教材」卡片

### 6. 训练配置 — 新弹窗
**操作**: 学生登录 → 选择任意病例 → 点击「开始训练」
**预期**: 弹出训练配置弹窗，顶部展示病例名称、描述、难度星级、患者信息（性别、年龄、主诉）；下方有「护理查体」开关、「基础/进阶」选项卡、「填写评估问卷」开关、时长滑动条（5-60分钟）

### 7. 训练配置 — 不同难度
**操作**: 在配置弹窗中 → 切换选择「基础」→ 点击「开始训练」→ 与患者对话 → 结束训练
**预期**: 「基础」模式下患者为被动应答，对话区无情绪和主动追问；「进阶」模式下患者有情绪变化和主动追问

### 8. 训练中功能面板
**操作**: 训练进行中 → 点击顶部功能面板图标 → 查看可用开关
**预期**: 仅「允许暂停计时」可切换；其余功能（情绪、查体等）为禁用状态，显示"此练习的插件配置由教师设定，不可更改"

### 9. 训练评分 — 后台通知
**操作**: 学生登录 → 完成一场训练对话 → 点击「结束训练」→ 在评分弹窗中点击「返回主页」→ 浏览其他页面，等待约 1-3 分钟
**预期**: 评分弹窗显示"评分在后台进行中，您可以先返回主页"提示；点击返回主页后可正常浏览其他页面；评分完成后右上角弹出"评分已完成！"通知，点击「查看」跳转到评分详情页

### 10. 训练评分 — 结果查看
**操作**: 收到评分完成通知后 → 点击「查看」→ 或进入训练记录列表 → 点击刚完成的记录
**预期**: 评分详情正常展示：总评分、各维度得分、优势、不足、遗漏内容、建议

### 11. 护理记录 — 表单缓存
**操作**: 训练进行中 → 打开「护理记录」面板 → 填写部分内容 → 切换其他面板再切回
**预期**: 之前填写的内容保留不丢失；不会出现表单被清空的情况

### 12. 对话区 — 打字指示器
**操作**: 训练中发送消息后等待患者回复 → 观察左下角按钮
**预期**: 患者回复中，左下角按钮变为药丸形，左侧有脉冲圆点和"患者正在回复…"文字；回复完成后按钮恢复为圆形箭头图标
