# v2026.06.21-8 测试清单

**版本**: v2026.06.21-7 → v2026.06.21-8
**环境**: https://test.205716.xyz

### 1. 患者自主反应
**操作**: 管理员在练习模板中启用「患者自主反应」→ 学生开始训练（选择启用了该功能的病例）→ 正常对话 → 等待 30-90 秒不发言
**预期**: 患者会主动发送一条自然的消息（非固定模板），消息带有「患者自主反应」标签

### 2. 查体结果卡片
**操作**: 学生开始训练（启用了查体功能的病例）→ 打开查体面板 → 执行体温、血压等测量
**预期**: 测量结果在对话中显示为精美卡片（带图标、类别标签、数值+单位），而非纯文本系统消息

### 3. 查体重连保留
**操作**: 学生执行多次查体操作 → 刷新页面 → 重新打开查体面板
**预期**: 已执行的查体操作历史保留，不会丢失

### 4. 自主反应进度条
**操作**: 学生开始训练（启用自主反应）→ 观察聊天输入框上方的进度条 → 等待不发言
**预期**: 进度条实时逐步填充（颜色从绿→黄→红），填充满后患者触发自主反应
