# v2026.06.22-17 测试清单

**版本**: v2026.06.22-16 → v2026.06.22-17
**环境**: https://test.205716.xyz

> 本次为火山引擎语音服务迁移（豆包大模型 v3）。TTS/ASR 实际发声与识别需管理员先在后台填入有效 API Key；未配置时语音功能应自动隐藏、不影响文本训练。

### 1. 语音服务凭证表单（管理员）
**操作**: 管理员登录 → 进入「成本管理 / 语音管理」页 → 查看凭证区
**预期**: 凭证区只有一个「API Key」输入框（不再是旧的 App ID + Token 两个框）；下方可见 TTS 音色、TTS 模型、采样率、格式与 ASR 接入模式等参数项

### 2. 保存语音配置
**操作**: 在语音管理页填入 API Key 与 TTS 音色 → 点击「保存配置」
**预期**: 提示「配置已保存」；重新进入页面时 API Key 显示为打码（如 `abc********xyz`），其余参数为刚保存的值

### 3. 测试 TTS 连通
**操作**: 在语音管理页点击「测试 TTS」按钮
**预期**: 配置有效时提示「TTS 测试通过」；配置无效/未填时提示具体错误（不再出现旧版 401 未授权）

### 4. 患者语音播放（学生）
**操作**: 学生登录 → 开始训练 → 与患者对话，等待患者回复
**预期**: 患者回复时有语音朗读；患者情绪不同（如紧张/防御 vs 平静）时语速、音量有可感差异

### 5. 语音输入与不可用降级（学生）
**操作**: 学生进入训练对话框，观察输入框右侧
**预期**: 语音服务可用时显示麦克风按钮，点击说话时输入框实时出现识别文字、结束后自动填入；语音服务未配置或不可用时麦克风按钮自动隐藏，仅能手动输入文字，训练流程正常不受阻
