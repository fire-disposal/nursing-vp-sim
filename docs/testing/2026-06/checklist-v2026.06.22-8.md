# v2026.06.22-8 测试清单

**版本**: v2026.06.21-9 → v2026.06.22-8
**环境**: https://test.205716.xyz

### 1. 情感语音合成 (TTS)
**操作**: 进入训练 → 发送任意消息 → 等待患者回复 → 检查语音播放
**预期**: 
- TTS 开关默认开启（TrainingHeader 右侧 Ear 图标）
- 患者回复后自动播放语音（火山引擎合成，带情感语调）
- 切换 TTS 开关 → 关闭后不再播放语音
- 语音播放期间，下方红色进度条暂停增长（患者不会打断自己）
- **注意**: 首次使用需在管理面板配置火山引擎密钥

### 2. 语音输入 (ASR)
**操作**: ChatInput 右侧点击麦克风按钮 → 说话 → 自动识别并发送
**预期**: 
- 点击麦克风按钮开始录音（红色脉冲动画）
- 浏览器弹出麦克风权限请求 → 允许
- 说完后点击停止 → 文本自动填入输入框并发送
- 拒绝麦克风权限 → 显示"语音识别失败，请重试"

### 3. 成本管理页面
**操作**: 导航到管理后台 → 侧边栏"成本管理"
**预期**:
- 页面加载，默认显示"总览仪表盘"Tab
- 仪表盘包含：预算进度环、今日/本月成本卡片、30天折线图、Top用户表
- 切换到"LLM API" Tab → 显示 LLM 密钥管理
- 切换到"语音服务" Tab → 显示语音配置表单 + 连通性测试按钮 + 用量统计
- 切换到"导出与检查" Tab → 日期范围选择 + 服务筛选 + JSON/CSV 导出

### 4. 语音服务配置
**操作**: 成本管理 → "语音服务" Tab → 填入 App ID + Token → 点击测试按钮
**预期**:
- "测试 TTS" 按钮 → 显示加载中 → 成功显示"TTS 连通正常"
- "测试 ASR" 按钮 → 同上 → "ASR 连通正常"
- 保存配置后，TTS/ASR 功能可用
- 月度预算设置后，仪表盘预算进度环正确显示

### 5. 声线分配
**操作**: 病例编辑 → 人格配置区域 → 查看声线选择下拉框
**预期**:
- 下拉框包含 7 种声线 + "自动（默认）"
- 选择"自动" → 系统根据患者年龄性别自动匹配声线
- 选择指定声线 → 训练中患者使用该声线

### 6. TTS 降级
**操作**: 关闭火山引擎语音服务 → 进入训练 → 发送消息
**预期**:
- TrainingHeader 语音指示灯变为黄色（浏览器回退中）
- 患者回复使用浏览器原生 TTS 朗读（无情感但可听到）
- 恢复火山服务后 → 指示灯自动切回绿色

### 7. 训练页面兼容性
**操作**: 完整进行一次训练（从病例选择到评分结束）
**预期**:
- 所有现有功能正常（聊天、情绪显示、体检面板、护理记录、评分）
- 麦克风按钮无异常干扰
- TTS 开关不影响训练流程

### 8. 成本导出
**操作**: 成本管理 → "导出与检查" Tab → 选择日期范围 → 选择服务类型 → 点击导出 CSV
**预期**:
- CSV 文件正确下载
- 包含日期、服务类型、调用次数、成功/失败数、费用列
- JSON 预览模式显示格式化数据
