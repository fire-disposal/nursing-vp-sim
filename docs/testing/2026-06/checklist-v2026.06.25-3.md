> 本次为较大版本：管理后台多页改用统一表格、表单改用统一校验，并修复一批 CRUD 安全/功能问题，请重点做回归。

### 1. 管理列表页整体回归
**操作**: 管理员登录 → 依次打开「学校管理」「问卷管理」「护理问答记录」「练习模板」「练习发布」「班级管理」→ 每页看列表、搜索框、筛选、翻页
**预期**: 各页数据正常显示；搜索/筛选/翻页即时生效；无空白或报错

### 2. 管理表单创建/编辑回归
**操作**: 在「学校/角色/班级/练习模板/练习发布/系统通知/个人资料/LLM 配置/密钥」中任选新建或编辑 → 先留空必填项点保存 → 再正确填写保存
**预期**: 必填项为空时就地红字提示并阻止提交；正确填写后保存成功并刷新

### 3. 未授权访问被拦截
**操作**: 用无对应权限的账号（如学生）→ 浏览器直接输入 /admin/users 或 /admin/schools 地址
**预期**: 不展示该管理页，自动跳回首页

### 4. 用户管理切换正常（回归）
**操作**: 管理员 → 用户管理 → 在用户列表与其它左侧菜单间反复切换
**预期**: 每次都能即时切换，不卡死

### 5. Prompt 版本激活真正生效
**操作**: Prompt 管理 → 对某场景激活一个版本 → 点「查看生效版本」
**预期**: 生效版本显示为刚激活的那个（不再激活后无变化）

### 6. 系统通知可编辑
**操作**: 系统通知 → 某条通知 → 点编辑按钮 → 改标题/内容 → 保存
**预期**: 通知卡片出现编辑按钮；保存后内容更新

### 7. 新建评分标准成功
**操作**: 评分标准 → 新建 → 结构化编辑器加维度/条目/锚点 → 创建；并调整「原始刻度」
**预期**: 创建成功（不再报缺失 id 类错误）；锚点输入框数量随原始刻度变化

### 8. 问卷模板题目编辑可保存
**操作**: 问卷管理 → 编辑某模板 → 增/删/改题目 → 保存 → 重新打开
**预期**: 题目改动已保存生效

### 9. 问卷回收数显示真实
**操作**: 问卷管理列表 → 看「回收数」列
**预期**: 显示真实已完成份数（不再恒为 0）

### 10. 管理端问答搜索可用
**操作**: 护理问答记录 → 搜索框输入学生姓名/学号/会话标题
**预期**: 列表按关键词过滤

### 11. 超管管理学校
**操作**: 超级管理员 → 学校管理 → 查看学校列表 / 删除一所无用户的学校
**预期**: 能看到全部学校；可删除空学校（不再恒被拦）
