### 2. 无权限页面自动回首页
**操作**: 用只有训练权限的账号登录 → 在地址栏直接访问统计/管理类页面
**预期**: 自动跳回首页，不会停在空白页

### 3. 教师「护理问答」入口出现
**操作**: 教师账号登录 → 查看左侧菜单
**预期**: 出现「护理问答」入口，点击可正常进入使用

### 4. 学生「我的问卷」入口
**操作**: 学生登录 → 查看顶部导航
**预期**: 出现「我的问卷」入口，点击可进入查看问卷

### 5. 角色管理「问卷管理」可勾选
**操作**: 管理员 → 角色管理 → 编辑一个自定义角色 → 查看权限勾选项
**预期**: 权限列表中出现「问卷管理」，可勾选并保存

### 6. 角色授权不能越权
**操作**: 用非超级管理员（如学校管理员）登录 → 角色管理 → 新建或编辑角色 → 尝试勾选自己没有的权限（如「API 管理」）→ 保存
**预期**: 保存被拒绝并提示无权授予该权限，无法把超出自身的权限授出

### 7. 训练对话流式回复
**操作**: 学生登录 → 开始一次训练 → 发送一句问诊消息 → 观察患者回复
**预期**: 患者回复逐字流式出现，过程连贯，不报连接错误、不反复重连

### 8. 语音识别（说话转文字）
**操作**: 训练中点击麦克风 → 说一句话 → 松开
**预期**: 语音被转成文字填入输入框，不报错、不卡住
