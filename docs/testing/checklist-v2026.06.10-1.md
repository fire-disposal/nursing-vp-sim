# v2026.06.10-1 测试清单

**版本**: v2026.06.08-5 → v2026.06.10-1
**环境**: https://test.205716.xyz

### 1. 管理员 LLM 调用日志增强
**操作**: 管理员登录 → 侧边栏进入「LLM 管理」→ 点击「调用监控」→ 在列表中找到带训练记录编号的行 → 点击该记录编号进入时间线 → 点击时间线中某次调用 → 查看弹出的请求/响应详情面板
**预期**: 能按记录编号筛选日志；点击记录编号跳转到该次训练的全部 LLM 调用时间线；点击单次调用弹出侧边详情面板，可查看请求和响应的完整内容

### 2. 管理员发布练习
**操作**: 管理员登录 → 侧边栏进入「练习发布」→ 点击「新建发布」→ 填写标题、选择练习模板和班级、设置开始和截止时间 → 点击保存
**预期**: 列表中出现新发布的练习，显示标题、班级、时间和状态（未开始/进行中/已结束）；可编辑和删除

### 3. 学生查看并完成作业
**操作**: 学生登录 → 首页查看「待完成练习」卡片区域 → 点击某条作业卡片 → 自动进入训练页面
**预期**: 若老师已发布作业，首页仪表盘显示作业卡片（含标题、练习名称、剩余时间）；点击卡片可直接开始训练；已完成或已逾期的作业显示对应状态标签

### 4. 用户个人信息完善
**操作**: 任意用户登录 → 点击右上角头像 → 选择个人信息 → 选择性别（男/女）→ 编辑昵称 → 点击保存
**预期**: 点击性别按钮后头像自动切换；保存后右上角头像和首页欢迎语同步更新；可修改密码

### 5. 训练页面右侧面板改版
**操作**: 学生登录 → 开始训练 → 观察右侧面板 → 依次点击各图标 Tab（患者信息、问诊清单、护理查体、护理记录、情绪状态、主动追问）→ 点击折叠按钮收起/展开面板
**预期**: 右侧面板默认展开，图标 Tab 可切换不同面板内容；问诊清单显示必问项进度、查体显示操作进度、护理记录显示填写进度；折叠后面板缩为窄条，再点击展开

### 6. 训练对话与显示优化
**操作**: 学生登录 → 开始训练 → 连续发送多条对话 → 观察聊天区滚动 → 执行体格检查操作 → 观察对话区是否出现检查结果 → 观察左侧情绪面板显示
**预期**: 聊天区自动滚动到最新消息，不出现滚动卡住的情况；患者回复内容完整不截断；计时器显示正常不重复结束；情绪面板正常显示患者情绪状态；体格检查结果以系统消息形式出现在对话区
