# v2026.06.18-1 测试清单

**版本**: v2026.06.17-3 → v2026.06.18-1
**环境**: https://test.205716.xyz

### 1. 管理员系统配置管理页面
**操作**: 管理员登录 → 侧边栏点击「系统配置」→ 查看配置项列表 → 修改某项配置的值 → 点击保存
**预期**: 页面显示系统配置项列表（如 LLM 参数、功能开关等）；修改后保存成功，配置生效

### 2. QA 问答接入教材知识库
**操作**: 学生登录 → 进入 QA 问答页面 → 输入一个护理相关的问题（如"青霉素过敏怎么处理"）→ 发送
**预期**: 系统回复内容更专业准确，引用了教材知识点；回复中包含检索到的参考内容

### 3. 训练存档与续训
**操作**: 学生登录 → 开始训练 → 发送几条对话后关闭页面 → 重新登录 → 进入训练记录 → 找到刚才的训练 → 点击「继续训练」
**预期**: 训练从上次中断处继续，历史对话完整保留；训练进度（阶段）保持不变

### 4. 评分卡环形动画与维度展示
**操作**: 学生完成一次训练 → 等待评分生成 → 在训练记录中点击查看评分 → 观察评分卡片
**预期**: 总评分以环形进度动画展示；各评分维度以柱状图显示得分和满分；维度名称清晰（如沟通能力、临床推理等）

### 5. 情绪系统升级 — 焦虑状态
**操作**: 学生登录 → 开始训练 → 在对话中输入带有攻击性或焦虑诱导的内容 → 观察患者头像
**预期**: 患者头像根据情绪变化显示不同边框颜色或状态；可从正常切换到焦虑等状态

### 6. 紧凑情绪指示器 + 主动追问进度条
**操作**: 学生登录 → 开始训练 → 观察页面顶部的情绪指示器 → 观察主动追问区域的进度条
**预期**: 情绪指示器紧凑显示当前患者情绪状态，不占用过多空间；主动追问进度条显示已回答/未回答项的数量和百分比
