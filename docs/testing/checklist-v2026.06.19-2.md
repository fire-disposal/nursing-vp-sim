# v2026.06.19-2 测试清单

**版本**: v2026.06.19-1 → v2026.06.19-2
**环境**: https://test.205716.xyz

### 1. 管理员系统通知管理页面
**操作**: 管理员登录 → 侧边栏进入「系统通知」→ 点击「新建通知」→ 填写标题、内容、选择发送方式（即时/定时）→ 点击发送
**预期**: 通知列表中出现新通知；选择即时发送后学生端立即收到；可编辑和删除已有通知

### 2. 系统通知定时发布
**操作**: 管理员登录 → 系统通知页面 → 新建通知 → 设置为定时发布 → 指定发布时间 → 保存 → 等待到设定时间
**预期**: 到设定时间后通知自动推送至全部用户；通知列表中显示"已发送"状态

### 3. 学生端通知铃铛
**操作**: 学生登录 → 观察页面右上角铃铛图标 → 点击铃铛 → 查看通知下拉列表 → 点击某条通知查看详情
**预期**: 有未读通知时铃铛显示红色角标数字；点击铃铛展开通知列表，显示标题和摘要；点击后标记为已读

### 4. 聊天输入体验优化
**操作**: 学生登录 → 开始训练 → 输入多行文本 → 按 Shift+Enter 换行 → 按 Enter 发送
**预期**: 输入框支持多行文本，按 Shift+Enter 换行不发送；按 Enter 直接发送；输入框高度随内容自适应

### 5. 患者打字指示器
**操作**: 学生登录 → 开始训练 → 发送一条消息 → 等待患者回复
**预期**: 患者回复前对话区显示打字动画（三个点跳动）；回复内容到达后动画消失，消息正常显示
