### 1. 训练评分流程
**操作**: 学生登录 → 开始病例训练 → 对话至少5轮 → 点击「结束训练」→ 等待评分
**预期**: 评分进度弹窗不再显示「返回主页」按钮；进度条实时更新百分比和阶段文字；评分完成后自动展示分数卡片；可点击「查看模型原始输出」查看 LLM 中间输出

### 2. 评分失败处理
**操作**: 学生登录 → 开始训练 → 快速结束（对话较少）→ 等待评分
**预期**: 若评分失败，弹窗显示具体错误信息（红色文字）；失败时显示「关闭」按钮可关闭弹窗

### 3. 超时自动结算
**操作**: 学生登录 → 开始训练 → 不操作直接等待倒计时归零 → 系统自动结束训练
**预期**: 超时后自动结束训练并触发评分；评分完成后可在记录中查看结果

### 4. 管理后台 API 管理
**操作**: 管理员登录 → API 管理页面 → 查看用途绑定列表
**预期**: 用途绑定列表中不再显示「模型」下拉选择器；快速创建绑定不再需要选择模型；绑定创建/编辑正常
