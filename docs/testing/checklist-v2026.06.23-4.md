# v2026.06.23-4 测试清单

**版本**: v2026.06.23-3 → v2026.06.23-4
**环境**: https://test.205716.xyz

### 1. 多个错误提示不再重叠（所有角色）
**操作**: 在断网或异常状态下连续触发多个会失败的操作（如连续点击多个保存/删除）→ 观察右下角弹出的错误提示
**预期**: 多条错误提示在右下角依次向上排列、互不遮挡；完全相同的错误文案只显示一条，不会重复刷屏

### 2. 评分失败也有通知（学生）
**操作**: 学生登录 → 结束一次训练 → 等待评分；若评分失败或超时 → 查看右上角铃铛
**预期**: 铃铛出现「评分失败」通知（以往只有成功才有提示）；评分完成或失败后铃铛红点即时更新，无需手动刷新页面

### 3. 通知铃铛的加载与时间显示（学生/教师）
**操作**: 点击右上角铃铛 → 查看通知列表
**预期**: 加载过程中显示「加载中…」，加载失败显示「加载失败，请稍后重试」（与「暂无通知」明确区分）；每条通知下方显示日期和时间

### 4. 系统通知：多行内容与即时发布（管理员）
**操作**: 管理员登录 → 进入「系统通知」页 → 点击「新建通知」→ 在「内容」框输入多行文字 → 定时时间留空 → 点击「创建」
**预期**: 内容框可输入多行；定时留空即为立即发布，并很快推送到用户铃铛；列表中「发布时间」按本地时间显示，与填写时间一致

### 5. 删除系统通知需二次确认（管理员）
**操作**: 在「系统通知」页点击某条通知右侧的删除（垃圾桶）图标
**预期**: 弹出确认框「确定删除这条系统通知？此操作不可撤销。」，确认后才真正删除，可取消

### 6. 训练页移除情绪坐标按钮（学生）
**操作**: 学生登录 → 开始一次启用情绪功能的训练 → 观察对话页右下角的浮动按钮
**预期**: 右下角不再出现「情绪状态」浮动按钮，也不再有弹出的情绪坐标图；患者情绪状态仍可在页面顶部的情绪栏看到
