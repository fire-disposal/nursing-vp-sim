### 2.2 开发 → 开发管理 → 接口设置

#### 微信登录（wx.login）

路径：**开发 → 开发管理 → 接口设置 → 登录**

本小程序使用 `wx.login` 获取临时 code，后端通过 `code2session` 换取 openid。

**无需额外申请**——此接口默认对所有小程序开放，但在代码审核时需要勾选「用户隐私保护」场景。

#### 用户信息（昵称、头像）

本小程序仅使用 `wx.login` + 用户自填昵称，不调用 `wx.getUserProfile` 或 `<open-data>` 组件，因此：

- **无需申请**用户信息相关接口
- **无需**在小程序前端展示用户信息授权弹窗

### 2.4 版本管理

路径：**管理 → 版本管理**

#### 开发版本

在开发者工具中点击「上传」后，版本会出现在开发版本列表。管理员可设为体验版。

#### 体验版

- 设置体验版后，可通过体验版二维码邀请测试用户
- 体验版无需审核，但需要将测试用户的微信号加入「体验成员」列表
- 路径：**管理 → 成员管理 → 体验成员 → 添加**

#### 提交审核

从开发版本中选择一个版本 → 提交审核：
1. 填写审核信息（功能页面截图、测试账号等）
2. 勾选使用的接口（本小程序：**wx.login**）
3. 填写隐私保护指引（需在 **设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引** 中先配置）
4. 提交后等待审核（通常 1-7 个工作日）

#### 发布上线

审核通过后，在版本管理中点击「提交发布」即可全网发布。

---

### 2.5 用户隐私保护指引

路径：**设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引**

必须填写并声明小程序收集的用户信息：

| 信息类型 | 用途说明 | 本小程序 |
|----------|----------|---------|
| 微信 OpenID | 用户唯一标识，用于登录和账号绑定 | ✅ 需要声明 |
| 用户填写的昵称 | 系统内显示名称 | ✅ 需要声明 |

填写指引：
1. 点击「用户隐私保护指引」→「填写」
2. 开发者处理信息：勾选「用户标识（OpenID）」和「用户自定义昵称」
3. 说明处理目的和方式
4. 保存并发布

---

### 2.6 小程序密钥（AppSecret）

路径：**开发 → 开发管理 → 开发设置 → 小程序密钥**

- AppSecret 用于后端 `code2session` 接口
- 对应后端 `.env` 中的 `WECHAT_SECRET` 变量
- 如果重置 AppSecret，需要同步更新服务器 `.env`

**当前后端已配置：**
```env
WECHAT_APPID=wx4c375b49b33f7b8d
WECHAT_SECRET=<从控制台获取>
```

## 四、CI/CD 与发布流程

```
本地开发 → git push master → GitHub Actions CI (自动测试)
                                   │
               git tag vX.X.X ──→ GitHub Actions Staging (自动部署 test.205716.xyz)
                                   │
                      手动触发 CD ──→ Deploy to Production (iomt.205716.xyz)
                                   │
                       开发者工具「上传」 ──→ 审核 → 发布
```

1. **后端**通过 Docker 镜像自动部署（Staging/CD workflows）
2. **小程序代码**需要手动在微信开发者工具中点击「上传」并提交审核
3. 上传前确保 `app.ts` 中 `baseUrl` 切换到正式地址

---

## 五、本地调试说明

在微信开发者工具中：
1. 点击右上角「详情」→「本地设置」
2. 勾选「**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**」
3. 此时可使用 `http://localhost:8000` 进行本地调试
4. 上传前务必取消勾选，确保远程接口连接正常
